# LESSON 1.1: What Is Programming?

## Lessons Learnt in LESSON 1.1

#### What is programming:

- Giving the computer a set of instructions in order to complete a task or reach a goal

#### Sequencing:

- The exact order and pattern in which instructions run in

#### Precison:

- The quality of being clear, exact and consistent

#### State: 

- The current status of something at a given moment.

**Key Concepts**: Program, Sequence, Precison, State

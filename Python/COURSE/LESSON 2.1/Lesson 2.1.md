# LESSON 2.1: INTRODUCTION TO PYTHON (WHY PYTHON)

## BENEFITS:

**Readable**: Simple and easy to read, write and understand
**Beginner freindly**: Simple clear rules
**Versatile**: Web, Data, AI, and Automation
**Popular**: Used by major tech giants in the world. Google, Netflix, Amazon etc
**Interpreted**: Program runs line after line, instant feedback
**Large library**: Thousand of pre-built tools

#### REAL WORLD APPLICATIONS:
- Web development
- AI/Machine Learning
- Data Analysis
- Scripting and Automation

## Key Concepts: 

- Readability (HLL - High Level Language) Writing a language or program in human readable english rather than computer hardware command

- Ecosystem (Library): A collection of prewritten programs written by other developers that can be plugged into your project to add new featrues

- Multi-Purpose: The ability of a language to handle many different type of task ranging from simple scritps to complex automations

# Lesson 4: How Python Runs Your Code (with output redirection and exit codes)

## Key Concepts

**Interpreter** - A software program that reads, translates and executes your code line by line.
**Compiler** - A program that translates your entire code file into machine language first, before running any of it.
**Execution** - The strict sequential path python follows to execute you code starting from line 1
**Redirect ouput** - The process in which we redirects the output of our code into a file rather than displaying it on the terminal
**Exit status**- The System number returned by computer upon completion of a program 0 means success and any other number apart from 0 means an error
**Command chaining** - The process of linking multiple terminal commands using logical operators such && or ||

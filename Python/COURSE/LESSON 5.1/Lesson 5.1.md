# Lesson 5: Python Keywords and Syntax


### Key Concepts

***Key word** - Built in words that has special meaning in python and can't be used to name a variable
**Resevered word** - Another name of for key word because python is already using it
**Syntax** - The rules that govern or guide how to correctly write python code
**Syntax Error** - A code in your code's grammar
**Comment (#)** - Used for starting a single line comment it is meant for humans to read not for the computer to execute
**Indetation** - Spaces at the beginning of the file to show what belongs to what
**Colon (:)** - A punctuation mark python uses to show the starting of a block of code

### Summary of key concepts

**Colon (:)** -  A colon means "what comes next belongs to what came before."
**Indetation** - All lines in the same block must have the same amount of indentation.


# Python Keywords Reference

Python reserves certain words as **keywords**. These words have special meanings in the language and cannot be used as variable, function, or class names.

| Category | Keywords | Description |
|----------|----------|-------------|
| **Values** | `True`, `False`, `None` | Built-in constant values representing truth, falsity, and the absence of a value. |
| **Logic & Comparison** | `and`, `or`, `not`, `is`, `in` | Logical operators and membership/identity comparison operators. |
| **Conditionals** | `if`, `elif`, `else` | Used for decision-making and conditional execution of code. |
| **Loops** | `for`, `while`, `break`, `continue` | Used to create loops and control loop execution. |
| **Functions** | `def`, `return`, `lambda`, `yield` | Used to define functions, return values, create anonymous functions, and generators. |
| **Classes** | `class` | Used to define classes (object-oriented programming). |
| **Error Handling** | `try`, `except`, `finally`, `raise`, `assert` | Used for exception handling, raising errors, and debugging assertions. |
| **Imports** | `import`, `from` | Used to import modules or specific objects from modules. |
| **Scope** | `global`, `nonlocal` | Used to modify variable scope inside functions and nested functions. |
| **Context Managers** | `with`, `as` | Used for resource management (e.g., opening files) and aliasing objects. |
| **Asynchronous Programming** | `async`, `await` | Used to define and execute asynchronous functions. |
| **Other** | `del`, `pass` | `del` deletes objects or variables; `pass` is a placeholder that performs no action. |

# Lesson 6: Variables and Primitive Types

### Key Concepts

**Variable** - A varaible is a container used to store different data types it's a labelled containter in the computer's memory used to store a specific piece of information. It can be any name but a reasonable sensible one though
**=** - Used for assingment of a value to a variable or the action of putting data inside the variable
**Data Type** - The specific category of information being  which determines which rules apply to it
**type() Function** - A built in tool in python that tells you what data type is assigned to a variable e.g

```python
Interger = 16
String = 'Mel CEO OF INFINITE TECHNOLOGIES'
print(type(Interger))
```
